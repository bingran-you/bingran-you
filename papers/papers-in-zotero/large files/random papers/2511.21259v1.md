CONSTRUCTING THOMPSON REPRESENTATIVES VIA POINTED LINKS
SUSANNA TERRON
Abstract. We extend Jones’ construction to obtain a surjective map from the Brown–Thompson group F3 to the set of pointed links up to pointed isotopy. We then introduce an operation on F3, and use it to define a new monoid (F3, ⋄), called the central monoid. Using the extended version of Jones’ construction, we obtain a surjective monoid homomorphism from the central monoid to the monoid of pointed links with connected sum. This allows us to introduce a standard form for connected sum representati-
ves in F3, and we extend this construction to a certain family of links by defining disjoint union and linking moves on F3.
1. Introduction
Inspired by questions arising from conformal field theory, Vaughan Jones introduced a construction associating links to elements of Thompson’s group F [Jon17] and its generalisation F3 [Jon19]. In analogy to the theory relating braid groups and knot theory, this construction gives a map F → Links similar to the closure map F
n Bn → Links. In the case of braids, surjectivity of the map is guaranteed by the Alexander Theorem, and a set of moves sufficient to establish when two braids give the same link is described by the Markov Theorem. In his paper Jones proved an Alexander type theorem showing that all links can be obtained from an element of F [Jon17, Theorem 5.3.1], proving that the map above is surjective. The question of when two group elements result in the same link is still unanswered. Maintaining the parallel-
 with braid groups, answering this question would result in a Markov type theorem for either F or F3. We call these elements Thompson representatives of the link. Various authors have explored the connection between Thompson’s group and knot theory, see for example [Aie20], [AN22], [AB24], [Lil24], [KLL24] and [RS25]. The aim of this paper is to introduce a standard form for representatives of certain links in the Brown–Thompson group F3 by defining operations on the group that correspond to opera-
tions on links.

3. Extension to pointed link
Denote by Links∗ the set of pointed links up to pointed isotopy, i.e. the set of links with a marked component considered up to link isotopy that preserves the marking. In this section we extend Jones’ result to obtain a surjective map into Links∗.
Each element of Links∗ corresponds to a pair (L, C), with L the isotopy class of the link and C its marked component. Note that, for any f ∈ F3, Jones’ construction gives us a preferred component in L(f ), corresponding to the component containing the closure of the roots of the trees. We call it the central component. We can therefore extend L to the following map.
Definition 3.1. Define L∗ : F3 → Links∗ to be the map associating to each f ∈ F3 the class of the link L(f ) with marked component the central component. We call the image of an element f ∈ F3 under L∗ a Thompson link.
Isotopic links may differ once one takes pointed isotopy, as the class depends on the marked component. For example, the links in Figure 6 correspond to the same class in Links but represent different classes in Links∗.

5.1. Prime decomposition. Given any knot K, we can now describe, up to prime components, how to obtain an element f of F3 in a standard form such that L(f ) = K. Recall that a knot is said to be prime if it cannot be expressed as the connected sum of two non-trivial knots. Any knot K has a prime decomposition K = P1# . . . #Pn, i.e. it can be written as the connected sum of prime knots P1, . . . , Pn, unique up to permutation [Lic97, Theorem 2.12].
