How to extract a paper for the site (kept out of the repo, so recorded here):

- Abstracts in the arXiv API carry raw TeX. Take the text from `https://arxiv.org/html/<id>` (LaTeXML) instead and map its MathML to `<i>`, `<sup>`, `<sub>`.
- In that HTML, Figure 1 is the first `<figure>` whose id ends in `.F1` (or `.F1.fig1` when the figure is a minipage); tables are `<figure id="…T<n>">`.
- Figures drawn as SVG or PDF have no image file there: crop them from the PDF with `pdftoppm -r 300 -x -y -W -H`.

## Environment lessons

- Start the dev server with `personal-site` as the working directory. `lib/posts.ts`, `lib/blog.ts` and the sitemap read files through `process.cwd()`, so `next dev personal-site` run from the repo root returns 500 on `/posts` and `/blog`.
- In a worktree without the skill submodules, run `./node_modules/.bin/next dev`, not `npm run dev`: the latter regenerates `lib/skills.generated.json` and `public/skill-files/` from a partial mirror.
- `/palace` needs `node scripts/build-palace.mjs` once per worktree (about two minutes); rebuild after editing `palace-inner`.
- Parallel Bash tool calls share one shell, so a `cd` in one changes the directory under the others. Use `( cd dir && cmd )` or absolute paths.
- Headless Chrome's `--screenshot` clamps the window to 500px wide and can hang with a fresh profile. For real mobile screenshots drive Chrome over the DevTools Protocol with `Emulation.setDeviceMetricsOverride`.
- While any route has a compile error, the Turbopack dev overlay covers every route.
- A full-page headless capture of a very tall page (the home page is about 12,000 px) can hang. Capture slices of 2,000 px or less.
- `next/image` loads lazily, so images below the fold are blank in a capture unless the script first sets `img.loading = "eager"` and waits for them.
- After deleting or renaming routes, run `next typegen` before `tsc`, or stale `.next/types` report missing pages.
- `npx eslint` with no path also lints the built palace bundles; lint `app lib components` instead.
