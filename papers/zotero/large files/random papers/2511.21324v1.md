DISTRIBUTIONS OF BOUNDED REAL SEQUENCES AND ASTORG-THALER’S QUESTION
ZHANGCHI CHEN, ZIHAO YE
Abstract. While studying the existence of wandering domains in complex dynamics, AstorgThaler posed a question concerning the distribution of bounded real sequences: for α > 1 that has the Pisot property, is β ln α
α−1 ∈ Q necessary for the existence of an increasing sequence of integers (nk)k⩾1 such that (nk+1 − αnk − β ln nk)k⩾1 converges to a cycle? When α is an algebraic number, we answer Astorg-Thaler’s question in the affirmative.
Keywords Pisot number, Linear recurrence, Birkhoff average measure, Weyl’s equidistribution theorem.
Mathematics Subject Classification 37F10, 37F40, 11K16, 37F80, 11J71.
1. Introduction

It is natural to ask for which (α, β) there exists an increasing sequence of integers (nk)k⩾1 such that (nk+1 − αnk − β ln nk)k⩾1 converges? The condition on α is well understood. Astorg-Thaler proved in [2, Theorem 1.10(2)] that such a sequence exists if and only if α has the Pisot property, a notion arising from the study of the distribution of powers of α modulo 1.
Definition 2. A real number α > 1 has the Pisot property if there exists some ξ > 0 such that lim
n→+∞ ∥ξαn∥ = 0, where ∥ · ∥ denotes the distance to the nearest integer.
Theorem 1.2. [5] If α > 1 is an algebraic number with the Pisot property, then it is an algebraic integer and is a Pisot number, in the sense that all its Galois conjugates have modulus strictly less than 1.
There is a long-standing question known as the Pisot–Vijayaraghavan problem, asking if any α > 1 with the Pisot property is algebraic. The condition for β is more complicated. For a sequence of integers (nk)k⩾1, and for θ ∈ R, define a sequence (mk)k⩾1 by
(3) mk := nk + ⌊kθ⌋.
Proposition 1.3. The real number β ln α
α−1 is the unique value of θ such that (nk+1 − αnk − β ln nk)k⩾1 is bounded if and only if (mk+1 − αmk)k⩾1 (defined by (3)) is bounded.
Astrog-Thaler introduced the following weaker version of convergence.
Definition 3. [2, Definition 1.9] For any positive integer l, a sequence (xk)k⩾1 is said to converge to a cycle of period l if the subsequence (xkl+j)k⩾1 converges for each 0 ⩽ j < l.
Now we can fully state Astorg-Thaler’s conditions on (α, β).
Theorem 1.4. [2, Theorem 1.10(2)] If there exists an increasing sequence of integers (nk)k⩾1 such that (nk+1 − αnk − β ln nk)k⩾1 converges to a cycle, then α has the Pisot property. Conversely, if α has the Pisot property and θ = β ln α
α−1 ∈ Q, then there exists an increasing sequence of integers (nk)k⩾1 such that (nk+1 − αnk − β ln nk)k⩾1 converges to a cycle.
Astorg and Thaler want to know whether θ ∈ Q is necessary in the second statement above. For a sequence of integers (mk)k⩾1, defined a sequence (ηk)k⩾1 by
(4) ηk := mk+1 − αmk + {(k + 1)θ} − α{kθ}.
Proposition 1.5. [2, Remark 10.9] The sequence of (nk+1 − αnk − β ln nk)k⩾1 converges to a cycle if and only if for (mk)k⩾1 and (ηk)k⩾1 (defined by (3) and (4)), (mk+1 − αmk)k⩾1 is bounded and (ηk)k⩾1 converges to a cycle.
Thus Astorg-Thaler’s question can be stated as follows.
Question 1.6. [2, Question 10.10] Let α > 1 be a real number with the Pisot property. Is θ ∈ Q necessary for the existence of an increasing sequence of integers (mk)k⩾1 such that (mk+1 − αmk)k⩾1 is bounded and (ηk)k⩾1 (defined by (4)) converges to a cycle?
Assuming that α is algebraic, we answer Astorg-Thaler’s question affirmatively.
Theorem 1.7 (Main Theorem). Let α > 1 be an algebraic number. Let (mk)k⩾1 be an increasing sequence of integers such that (mk+1 − αmk)k⩾1 is bounded. Then the sequence (ηk)k⩾1 (defined by (4)) converges to a cycle if and only if θ is rational.
By combining [2, Theorem 1.10(2)], we draw the following conclusion.
Corollary 1.8. Assuming that the Pisot—Vijayaraghavan problem has an affirmative answer, i.e. any α > 1 with the Pisot property is algebraic, then there exists an increasing sequence of integers (nk)k⩾1 such that (nk+1 − αnk − β ln nk)k⩾1 converges to a cycle if and only if α is a Pisot number and β ln α
α−1 is rational.
