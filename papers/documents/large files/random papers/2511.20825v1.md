SPECTRAL ORTHOGONALITY OF SPECIAL FLOWS
MINGCHENG SHENG
Abstract. In this paper, we study the spectral orthogonality problem for special flows built over
irrational rotations under two different types of roof functions:
1) the roof functions are real analytic.
2) the roof functions are piecewise C1 with one discontinuity. These flows are also known as von
Neumann flows.
We show that if {Tαf } is as in 1) and weak mixing, then for a Gδ dense set of β, we have that {T f
β} is weak-mixing and is spectrally orthogonal to {Tαf }. On the other hand, if {Tαf } is as in 2), then for a
full measure set of β, the flows {Tαf } and {T f
β } are spectrally orthogonal.
1. Introduction
Given two continuous probability preserving dynamical flows T = (Tt)t∈R on (X, μ) and R = (St)t∈R
on (Y, ν), there are several ways to measure how different these systems are. The most classical is
the isomorphism relation where the two systems are isomorphic if there exists an invertible measure
preserving transformation S : X → Y such that S ◦ Tt = Rt ◦ S for every t ∈ R. A stronger notion is
disjointness introduced by Furstenberg [7]. Two systems are disjoint (in the sense of Furstenberg) if the
only joining between them is the product measure. An even stronger notion is spectral orthogonality or
spectral disjointness. Two systems are spectrally disjoint if their spectral measures (see Section 2.3) are
orthogonal. It follows that spectral orthogonality implies (Furstenberg) disjointness which implies non
isomoprhism. This paper is concerned with studying spectral orthogonality for some classes of special
flows on the two torus which come from reparametrizations of linear toral flows. Recall that for the
classical linear flows on T2 the isomorphism problem is well understood. It then follows that two such
flows are spectrally orthogonal if and only if their rotation numbers are linearly independent over Q. Note
that this condition is also equivalent to Furstenberg disjointness. A more complicated case arises from
smooth reparametrizations of linear flows. These flows were first studied by Kolmogorov,[12] who showed
that if the rotation number of the linear flow is Diophantine (see 2.2), then the reparametrized flow is
smoothly conjugated to the corresponding linear flow and so it has pure point spectrum. However, the
case of a Liouvillian rotation number is fundamentally different. In 1967, Shklover[14] proved that there
are analytic reparametrizations which are weak mixing and so the spectrum is continuous. The main
goal of this paper is to study spectral orthogonality for the class of weakly mixing reparametrizations
of Liouvillean flows. Considering a Poincare section, these flows can be viewed as special flows over
irrational rotations(see the introduction of [5] for a short explanation). Denote Tαf by the special flow
over a rotation Rα(x) = x + α under a roof function f (see 2.1).
Our main results are:
Theorem 1.1. Given a Liouville number β and a real analytic function f so that the special flow T f
β is
weak mixing, there is a Gδ dense set of α such that Tαf is weak mixing and is spectrally orthogonal to T f
β.

The orthogonality problem has been studied for several classes of flows and maps. For example,
Chaika[2] showed in 2012 that every ergodic transformation is disjoint(in the sense of Furstenberg) from
almost every interval exchange transformation. Also, Krzysztof Fraczek, Adam Kanigowski, and Corinna

sponding special flows are spectrally orthogonal. More results on spectral orthogonality and Furstenberg
disjointness can be found in [1],[9],[8],[13], etc.
Our methods also applies to another type of special flows called the Von Neumann flows, see chapter
7 for the definition. In this case we show:
Theorem 1.2. For every α ∈ [0, 1]/Q, there exists a full measure set Sα, m(Sα) = 1, such that for every
β ∈ Sα, the flows T = Tαf and R = T f
β are spectrally orthogonal.
The isomorphism problem of Von Neumann flows were first studied by Kanigowski and Solomko [10].
They showed that every two Von Neumann flows with the same rotation number but under roof functions
of different slope are always non-isomorphic. In contrast, we establish a much stronger conclusion of
spectral orthogonality in a more subtle setting where two roof functions share the same slope. The
trade-off is that our result applies only to a full measure set of system parameters.
Our main tool to prove spectral orthogonality is a criterion from [6], which roughly says that if there
exists a time sequence {tn} that serves as a rigidity sequence for one flow but a mixing sequence for the
other, then the two flows are spectrally orthogonal. We will later establish that the sequence generated by
the convergents of the base rotation number always constitutes a rigidity sequence. The problem is thus
reduced to showing that a large set of special flows exhibits mixing behavior along this same sequence of
convergents.
