DISTANCE TO REGULAR ELEMENTS AND POLAR
DECOMPOSITIONS IN A C*-ALGEBRA
HANNES THIEL
Abstract. We show that the distance from an element of a C∗-algebra to the set of regular elements is the infimum of the δ > 0 for which the δ-cutdown of the element admits a polar decomposition within the algebra. This parallels results of Pedersen and Brown-Pedersen describing the distance to invertible and quasi-invertible elements through polar decompositions of cutdowns whose polar parts are unitaries or extreme partial isometries.
1. Introduction
An element a of a C∗-algebra A is called regular if there exists b ∈ A such that a = aba. It is well known that this occurs precisely when a is well-supported, meaning that 0 is isolated in the spectrum of a∗a, or, equivalently, when a has closed range, that is, when π(a) has closed range for every representation π of A on a Hilbert space; see [HM92] and [Bla06, Paragraphs II.3.2.9 and II.3.2.10]. In this situation a admits a polar decomposition a = v|a|, where v is a partial isometry in A and |a|-

This mirrors the case of invertible elements, which always admit polar decompositions with unitary polar parts; the passage from invertible to regular elements corresponds to replacing the unitary by a partial isometry. Every element of a von Neumann algebra admits a polar decomposition a = v|a|, and in that setting the partial isometry v is uniquely determined by the requirement that v∗v and vv∗ are the support projections of |a| and |a∗|, respectively. For an element a of a C∗-algebra A, the-
 canonical polar decomposition a = v|a| exists in the von Neumann algebra A∗∗. The positive part |a| always belongs to A, and if a is regular then the partial isometry v lies in A as well. In general, however, v need not belong to A. In this paper we use a weaker notion: we say that a ∈ A admits a polar decomposition in A if there exists some partial isometry w ∈ A such that a = w|a|, without imposing the uniqueness conditions on w that are part of the definition of the polar decomposition in the -
von Neumann algebra setting. This terminology is inspired by Pedersen [Ped89]. Even this weaker condition need not hold in general. For example, for the function f ∈ C([0, 1]) defined by f (t) = t exp(i/t) for t > 0 and f (0) = 0, there is no partial isometry w ∈ C([0, 1]) with f = w|f |.
We establish a precise relationship between the distance from an element to the set Areg of regular elements in a C∗-algebra A and the existence of polar decompositions for suitable cut-downs of the element. Recall that for δ > 0, the δ-cut-down of a positive element a is defined by functional calculus for the function t 7→ max{t − δ, 0}, and is denoted (a − δ)+. Theorem A (2.4). Let a be an element in a C∗-algebra A, with polar decomposition a = v|a| in A∗∗. Then for γ ≥ 0, the following are equivalent:
(1) We have dist(a, Areg) ≤ γ. (2) For every δ > γ, there is a partial isometry w ∈ A such that weδ = veδ, where eδ denotes the spectral projection of |a| in A∗∗ associated to (δ, ∞). (3) For every continuous function f : R → R vanishing on a neighborhood of [0, γ], the element vf (|a|) admits a polar decomposition within A. (4) For every δ > γ, the δ-cut-down of a admits a polar decomposition within A.
The case dist(a, Areg) = 0 is of particular interest and has been considered before, for example in work of Xue, who proved in [Xue07, Proposition 2.1] that an element a belongs to the closure of Areg precisely when it has ‘approximate polar decompositions’ in the sense that for every ε > 0 there exists a partial isometry w ∈ A such that ∥a − w|a|∥ < ε. Our result strengthens this significantly: we obtain actual polar decompositions for all cut-downs of a and, more generally, for all elements of t-
he form vf (|a|), where f is a positive, continuous function vanishing near 0. In forthcoming work [Thi25], we will apply the results of this paper to study C∗-algebras that contain a dense set of regular elements.
2. Proof of the main result
An element a in a C∗-algebra A is said to be Moore-Penrose invertible if there exists b ∈ A such that a = aba and b = bab, and such that ab and ba are projections. In this case, the stated conditions determine b uniquely, and one calls it the MoorePenrose inverse of a, denoted by a†.
It is known that every regular element in a C∗-algebra is Moore-Penrose invertible; see [HM92]. Let us give some details. Let a be a regular element in A. Then the partial isometry v of the canonical polar decomposition a = v|a| in A∗∗ belongs to A. Further, there is some ε > 0 such that the spectrum of |a| satisfies
σ(|a|) ⊆ {0} ∪ [ε, ∞).
It follows that the function g : R → R given by g(t) = 0 for t ≤ 0 and g(t) = 1
t for t > 0 is continuous on σ(|a|), and we have
g(|a|)|a| = v∗v.
The Moore-Penrose inverse of a is then
a† = g(|a|)v∗.
This shows that a† belongs to the C∗-algebra generated by a. It follows that regularity is independent of the containing C∗-algebra. In particular, an element is regular in A if and only if it is regular in A∗∗. Further, if a is contained in a

We are now ready to prove the main result (Theorem A), which characterizes the distance of an element to the set Areg of regular elements in a C∗-algebra A.
Theorem 2.4. Let a be an element in a C∗-algebra A, with polar decomposition a = v|a| in A∗∗. Then for γ ≥ 0, the following are equivalent:
(1) We have dist(a, Areg) ≤ γ. (2) For every δ > γ, there is a partial isometry w ∈ A such that weδ = veδ, where eδ denotes the spectral projection of |a| in A∗∗ associated to (δ, ∞). (3) For every continuous function f : R → R vanishing on a neighborhood of [0, γ], the element vf (|a|) admits a polar decomposition within A.

Proof. It follows directly from Lemma 2.3 that (1) implies (2). We verify the implications (2)⇒(3), (3)⇒(4), and (4)⇒(1). ‘(2)⇒(3)’: Let f : R → R be a continuous function vanishing on [0, δ] for some δ > γ. By assumption, there is a partial isometry w ∈ A such that weδ = veδ. Then
vf (|a|) = veδf (|a|) = weδf (|a|) = wf (|a|),
which shows that wf (|a|) is the desired polar decomposition of vf (|a|) inside A.
‘(3)⇒(4)’: This follows since for every δ > γ, the δ-cut-down of a is of the form vf (|a|) for a continuous function f : R → R vanishing on a neighborhood of [0, γ].
‘(4)⇒(1)’: Let δ > γ. By assumption, aδ admits a polar decomposition aδ = w(|a| − δ)+ in A. We view A as an ideal in its minimal unitization Ae, and we use 1 to denote the unit of Ae. Given ε > 0, the element ε1 + (|a| − δ)+ is strictly positive and therefore invertible in Ae. It follows from Lemma 2.1 that the element
w ε1 + (|a| − δ)+
is regular. Note that w ε1 + (|a| − δ)+ belongs to A, and therefore to Areg. We deduce that
dist(a, Areg) ≤ a − w ε1 + (|a| − δ)+
≤ ∥a − aδ∥ + w(|a| − δ)+ − w ε1 + (|a| − δ)+ ≤ δ + ε.
Since this holds for all ε > 0 and all δ > γ, we get dist(a, Areg) ≤ γ. □
Corollary 2.5. Let a be an element in a C∗-algebra A, with polar decomposition a = v|a| in A∗∗. Assume that a belongs to the closure of Areg. Then:
(1) For every δ > 0, there is a partial isometry w ∈ A such that weδ = veδ, where eδ denotes the spectral projections of |a| in A∗∗ associated to (δ, ∞). (2) For every continuous function f : R → R vanishing on a neighborhood of {0}, the element vf (|a|) admits a polar decomposition within A. (3) For every δ > 0, the δ-cut-down of a admits a polar decomposition within A.
