- Answer in short: a compiler goes to the Compiler board (suite@1, contract `qccd.compiler@1`, ranked by `speedup` = geomean T_jones(ref)/T_jones(yours) over pairs both compiled validly). A device goes to an Architecture board (T_jones ms/round; memory boards rank LER/round under qccd-noise@1). A toolchain with its own physics cannot be ranked; only the unranked /reproduce/ route fits it.

It was compiled from a 36-ancilla variant circuit, so a new submission can't be compared with it.
