New Obstacles to Multiple Recurrence
Ryan Alweiss ∗
November 27, 2025
Abstract
We show that there is a set which is not a set of multiple recurrence despite being a set of recurrence for nil-Bohr sets. This answers Huang, Shao, and Ye’s “higher-order” version of Katznelson’s Question on Bohr recurrence and topological recurrence in the negative. Equivalently, we construct a set S so that there is a finite coloring of N without three-term arithmetic progressions with common differences in S, but so that S lacks the usual polynomial obstacles to arithmetic progressions.
1 Introduction
A central and long-standing open problem in the field of topological dynamics is “Katznelson’s Question”, on whether a set of Bohr recurrence is a set of topological recurrence. This question was raised by a 1968 paper of Veech [21] and implicitly before that in a 1954 paper of Følner [5]. However, in a classic example of Stigler’s law, it is often referred to as “Katznelson’s question”, because Katznelson popularized the question and wrote a beautiful paper [16] connecting it to the chromatic num-
ber of abelian Cayley graphs. In this paper, via a Furstenberg correspondence principle type argument in symbolic dynamics, he shows that Bohr recurrence is equivalent to topological recurrence if and only if every abelian Cayley graph with finite chromatic number has a finite coloring via Bohr sets. Let us recall the equivalent dynamical and combinatorial definitions of Bohr and topological recurrence, and some basics of topological dynamics. These appear widely in the literature (see for instanc-
e [16] [9] [6]). Recall that ||x||R/Z = min({x}, 1 − {x}) is the distance between x and the nearest integer.
Definition 1.1 (Bohr recurrence, combinatorial definition). A set S ⊂ Z is a set of Bohr recurrence if and only if for all nonzero α1, · · · , αk ∈ R and all ε > 0 there exists some s ∈ S so that for all 1 ≤ i ≤ k, ||αis||R/Z < ε.
We will also formally define a Bohr set.
Definition 1.2 (Bohr set). A Bohr set is a set S parameterized by a k-tuple of reals (α1, · · · , αk) and ε, consisting of the s so that ||αis||R/Z < ε for all 1 ≤ i ≤ k.
The parameter k is called the dimension and ε is the width. Later we will define a complexity of a nil-Bohr set, which will be Θ(max(k, 1/ε)) for ordinary Bohr sets. Equivalently a set is a set of Bohr recurrence if it is not contained in the complement of a Bohr set, or equivalently in a finite union of complements of one-dimensional Bohr sets. Sometimes

Definition 1.3 (Bohr recurrence, dynamical definition). A set S ⊂ Z is a set of Bohr recurrence if and only if for all k ∈ N and all rotations T (x1, · · · , xk) = (x1 + α1, · · · , xk + αk) on the torus (R/Z)k, there exists a point x ∈ (R/Z)k and a subsequence S′ of n ∈ S so that limn∈S′ T n(x) = x.
The two definitions are readily seen to be equivalent. Since torus rotations are isometries, if T nx → x is true for a single point then it is true for all points, so it would be equivalent to change the quantifier on x from “there exists” to “for all”. We only consider S with 0 ∈/ S, as if 0 ∈ S then all notions of recurrence are trivial. In general dealing with S ⊂ N is equivalent to dealing with S ∪ −S ⊂ Z, so we will assume for the remainder of this paper that S ⊂ N. This is important, because-
 a general topological system is not necessarily invertible, so T −1 may not make sense. Recall that if S is a subset of a group G, the Cayley graph Cay(G, S) on an abelian group G has all elements of G as vertices and a, b in G are adjacent if and only if a − b ∈ (S ∪ −S). Recall also that the chromatic number of a graph is the minimal number of colors needed to color the vertices so that no two vertices of the same color are adjacent.
Definition 1.4 (Topological recurrence, combinatorial definition). A set S ⊂ N is a set of topological recurrence if and only if the Cayley graph Cay(Z, S) on Z generated by S has infinite chromatic number.
Topological recurrence is the most general form of recurrence, applying to all dynamical systems.
Definition 1.5 (Topological recurrence, dynamical definition). A set S ⊂ N is a set of topological recurrence if for every compact dynamical system (X, T ), where X is a compact metric space and T is a continuous map on X, there exists a point x ∈ X and a subsequence S′ of S so that limn∈S′ T nx = x.
It was Katznelson [16] who proved the equivalence of these two definitions of topological recurrence, giving the eponymous conjecture its combinatorial form. One direction is relatively simple. If a set S is not a set of dynamical topological recurrence, then one can use the dynamical system to come up with a coloring of the Cayley graph. In particular there will be some ε so that d(T nx, x) > ε for all n ∈ S. Now cover the compact space by ε-balls for a suitably small ε, and color m ∈ N by which -
ε-ball T m(x) ends up in. The other direction, using a coloring to construct a dynamical system, follows from an argument of Katznelson that makes use of symbolic dynamics, and bears some resemblance to the Furstenberg correspondence principle. A set of topological recurrence must be a set of Bohr recurrence. This is readily seen both from the topological definition, as a circle rotation is a special kind of dynamical system, and from the combinatorial version, as if S a set that is not a set of B-
ohr recurrence it is easy to construct a finite coloring by taking all of the nαi modulo 1, up to an error of ε. Hence we can state Katznelson’s question explicitly as follows.
Conjecture 1.6 (Katznelson’s question). If S is a set of Bohr recurrence, then is S necessarily a set of topological recurrence?

Definition 1.7 (Topological multiple recurrence, dynamical definition). A set S ⊂ N is a set of topological d-recurrence if for every compact dynamical system (X, T ), where X is a compact metric space and T is a continuous map on X, there exists a point x ∈ X and a subsequence S′
of S so that for all 1 ≤ d′ ≤ d, limn∈S′ T d′nx = x.
In other words, T nx, T 2nx, · · · , T dnx all go to x along this sequence S′ of n. So we have T nx → x, T 2nx → x, · · · , T dnx → x simultaneously along this sequence S′. For d = 1, this is the ordinary notion of recurrence.
Definition 1.8 (Topological multiple recurrence, combinatorial definition). A set S ⊂ N is a set of topological d-recurrence if for every finite coloring of N, there is a monochromatic (d+1)-term arithmetic progression with common difference in S.
Equivalently, the (d + 1)-hypergraph with edges (x, x + s, · · · , x + ds) for s ∈ S has infinite chromatic number. In other words, restricted van der Waerden with differences in S is true for (d + 1)-term arithmetic progressions. For d = 1 this is readily seen to coincide with the Cayley graph definition. As before, this combinatorial definition is equivalent to the dynamical one, see for instance [13], Theorem 2.5. In [15], the notation FBird is used for the family of sets of topological d-recur-
rence. For restricted van der Waerden, on top of the usual obstacles in Katznelson’s question, there are higher degree obstacles. If s is far from a multiple of an irrational number like π, then x, x + s, x + 2s cannot all be too close modulo π. If 2s2 is far from a multiple of π, then because x2 − 2(x + s)2 + (x + 2s)2 = 2s2, the squares of x, x + s, x + 2s cannot all be very close to each other modulo π as well, which yields a finite coloring where x is colored by x2 modulo π up to a small error-
. In general there will be polynomial obstacles up to degree d. So the natural question here is whether there are any other obstacles, with the caveat that one has to also worry about “generalized polynomials” or “bracket polynomials” like s⌊s⌋. These generalized polynomials are formally defined in [15], but we will not define them yet. In the dynamics literature, these correspond to nilmanifolds. Multiple recurrence for Bohr sets is equivalent to single recurrence, but there is a higher-order not-
ion of Bohr recurrence called “nil-Bohr recurrence”. It was originally defined dynamically in [12] and is the main object of study in [15]. We state it here for completeness. For a formal definition of a (d-step) nilsystem, one can for instance consult [15], but again it is not so crucial for the present paper.

A subtorus of (R/Z)m+k is defined to be the set of points where some set of linear forms with integer coefficients vanish, and the codimension is the number of independent linear forms needed to generate this vanishing set. For our purposes we need a slight modification of Leibman’s result.
Theorem 2.7 (Leibman). Let B = {B1, · · · , Bk} be a family of equi-distributed basic generalized polynomials and let ε > 0. If α1, · · · , αm are rationally independent irrational numbers, then the image of the map n → ({nα1}, · · · , {nαm}, B1(n), · · · , Bk(n)) which we denote as (Pm(n), B(n)) is ε-dense in some Ok(1) codimension sub-torus of (R/Z)m+k.
Proof. By Theorem 0.1 of [19], the last k coordinates will equidistribute over the torus (R/Z)k. Now reveal the αi one by one. At each step, the new αi will either be rationally independent from all of our existing gen-polynomials {nβ} (i.e. the already revealed {nαi} and the {nβ} from B), in which case {nαi} will jointly equidistribute, or it will be a rational linear combination of the β. Because the αi are rationally independent, the latter case will occur only Ok(1) times.
In Theorem 2.7, it is equivalent to restrict n to be bounded by some function F of (α1, · · · , αm), ε, and B. For our purposes we will need an infinitary corollary of Theorem 2.7. We first record a slightly refined version. First there exists a “complexity” function c(B, ε) on nil-Bohr neighborhoods with some useful properties. We say that (B, ε) has complexity at most C if it can be expressed as the pointwise limit of nil-Bohr neighborhoods with dimension at most C, degree at most C, and width a-
t least 1/C. So C is a bound on the parameters of the nil-Bohr set. In order to compute the exact
8

complexity of (B, ε), we take the infimum of these upper bounds. In particular, this complexity function goes to infinity with the inverse width 1/ε, the degree d, and the dimension k, and a pointwise limit of (B, ε) with complexity at most C also has complexity at most C.
Theorem 2.8 (Leibman, refined). There exists an explicit F ′ so that for any nil-Bohr set (B, ε), it holds that F ((α1, · · · , αm), ε, B) ≤ F ′((α1, · · · , αm), c(B, ε)).
Proof. We prove this via compactness. Assume there exists (α1, · · · , αm) and a sequence of (B, ε) with c(B, ε) ≤ C so that F ((α1, · · · , αm), ε, B) tends to infinity. By compactness, a subsequence of the (B, ε) has some nil-Bohr set (Bl, εl) also of complexity bounded by C as a pointwise limit. But then F (α1, · · · , αm, Bl, εl) = ∞, a contradiction.
We need an infinitary corollary of this refinement for our purposes.
Theorem 2.9 (Leibman, infinitary corollary). There exists a sufficiently quickly shrinking sequence αi so that the following holds. Let B1, · · · , Bk be equi-distributed basic generalized polynomials. If m = m(ε, B1, · · · , Bk) is sufficiently large, then the image of the map n 7→ ({nα1}, · · · , {nαm}, B1(n), · · · , Bk(n)) = (Pm(n), B(n)) for n ranging and sufficiently smaller than 1/αm+1 is ε-dense in some Ok(1) codimension sub-torus of (R/Z)m+k.
Proof. By Theorem 2.8 we may pick a sequence of αi that goes to zero quickly enough so that for any B and ε, for sufficiently large m we have F (α1, · · · αm, B, ε) is sufficiently smaller than 1/αm+1. For instance if we guarantee that 1/αm+1 is much larger than F ′(α1, · · · αm, m) ≥ F (α1, · · · , αm, B, ε) for c(B, ε) ≤ m, then for any fixed (B, ε) we will have that F (α1, · · · αm, B, ε) will be sufficiently smaller than 1/αm+1 for m which is a large enough function of c = c(B, ε).
Theorem 2.10. If we take a sequence of αi satisfying the conditions of Theorem 2.9, then for any nil-Bohr set B, P (S) ∩ B ̸= ∅.
Proof. Let εi be a sequence that goes to 0 sufficiently quickly. When n ranges but stays sufficiently small compared to 1/αk+1, we have that for sufficiently large m (Pm(n), B(n)) intersects Sm × (−εk, εk)k, because m was chosen to be sufficiently large so that Sm meets all ordinary Bohr sets of complexity Ok(1). So we can find some n so that Pm(n) ∈ Sm and n is sufficiently smaller than 1/αk+1. By the size bound on n we have P (n) ∈ S∞ and n ∈ SN. Since the coordinates of B(n) have R/Z norm less -
than εk, n is in the nil-Bohr set B. This concludes the proof.
A remark about nilmanifolds is in order. We do not use them here, but our results could be phrased equivalently in those terms. Section 2 of [19] describes the correspondence between equi-distribution of generalized polynomials and the equi-distribution over nilmanifolds from [18]. The correspondence between generalized polynomials and nilmanifolds was first proved in [2] and is cited as Lemma 2.3 of [19]. Theorem 2.9 of [7] is the quantiative version of Theorem 1.9 of [7], the main theorem of [18-

3 Concluding Remarks and Open Questions
The most obvious open question here is Katznelson’s question. In view of our disproof of the higher-order version, we conjecture that the answer should be negative.
Conjecture 3.1. There is a set S ⊂ N which is a set of Bohr recurrence but not a set of topological recurrence.
9

As usual we also state the combinatorial form of this conjecture.
Conjecture 3.2. There is S ⊂ N so that the Cayley graph on Z generated by S has a finite chromatic number, but does not admit a finite coloring via Bohr sets.
One reason to believe Katznelson’s question has a positive answer is that a “zero density exception” version is known due to [5]. In particular, if A is a dense subset of Z, then S − S contains a 1 − o(1) proportion of a Bohr set. Katznelson’s question is equivalent to the same claim except with A syndetic and without the o(1) proportion, see for instance [6]. A similar “zero density exception” of the higher-order Katznelson was proved in [15], but we have proved here higher-order Katznelson has a-
 negative answer. We generally believe that if Katznelson’s question has a positive answer, the proof somehow relies on topology. Indeed Glasscock, Koutsogiannis, and Richter [6] prove some special cases by using the intermediate value theorem, and [17] relies on the topological lower bound for the chromatic number of the Kneser graph. We mention one important obstacle to extending something like our construction to settle the full Katznelson’s question. Let G be an Abelian group. Then an element -
of Gm in the generating set with sum of coordinates 0 can be written in the form (a1−a2, a2−a3, · · · , am−1−am, am−a1), so the cyclic shifts (a1, a2, a3, · · · , an) and (a2, a3, · · · , an, a1). Hence, we cannot simply take a function of each coordinate and add it up the way we considered (e(x) − 1) here. Unfortunately, this kind of “cyclic shift” obstacle destroys many potential counterexamples to Katznelson’s question, and any kind of high-dimensional projection must break this sort of symmetr-
y. Another interesting direction is to consider the finite field setting. One can also consider analogues of Katznelson’s question over positive characteristic. This was asked by Ben Green over characteristic 2 ([8], Problems 52 and 53) and also by John Griesmer [9] over more general characteristic p. We can similarly ask the higher-order version of Katznelson’s question in characteristic p for p > d. We state two such versions for 3-term progressions.
Question 3.3. Let p1, p2, · · · , pn, · · · ≥ 3 be an increasing sequence of primes, and say we have a sequence Gi of Cayley graphs on Z/pi with uniformly bounded chromatic number C. Is there a uniform constant K so that the generating set of Gi is contained in the union of K sets ||Pj(x)/p||R/Z > 1/K, where Pj are polynomials on Z/pi of degree at most 2?
In other words, can we always find a bounded number K of quadratics Pj(x) so that any x in the generating set is mapped by at least one of the quadratics to a point that is not in the interval (−p/K, p/K)?
Question 3.4. Let p ≥ 3 be a fixed prime, and say we have a sequence of Cayley graphs Gi on (Z/p)n for a sequence of n = ni with uniformly bounded chromatic number C. Is there a uniform constant K so that the generating set of Gi is contained in the union of K sets Pj(x) ̸= 0, where Pj are quadratic forms on (Z/p)n of degree at most 2?
A few comments are in order about why our example does not immediately resolve the above questions. Our example in some sense relies on the infinite bracket polynomial P
i{nai}2. In
modulo 1, x and x2 are independent. However, in modulo p the value of n determines the value of n2, and P
i(nai mod p)2 = n2(P a2

In general, it is also true that Z/p and R/Z “look different” from the standpoint of arithmetic progressions of length 3 or greater. See [4] for discussion about this. We do not make any attempt at all to optimize the number of colors used in our construction. With our ideas it seems difficult to beat the bounds from-
 the unit distance in the plane. Let us also mention that while it is simple to check that at least 3 colors are necessary for any example answering Katznelson’s Question in the negative [6], in this setting of 3-term and longer progressions we do not even know if we can have a counterexample using only 2 colors.

Concerning counterexamples with only 2 colors, we also mention here the 2-large versus large conjecture of Brown, Graham, and Landman [3]. A set S is large if it is a set of d-topological recurrence for all d, so that restricted van der Waerden with restricted common difference s ∈ S is true for arbitrarily long arithmetic progressions. A set S is 2-large if any 2-coloring of N has arbitrarily large arithmetic progressions with common difference in S. Brown, Graham, and Landman asked if 2-large s-
ets are large. We have constructed the first example of a set that is not large but meets every nil-Bohr set. We conjecture that it is necessary to do so to refute the 2-large versus large conjecture.
Conjecture 3.5. If S is not a set of d-nilBohr recurrence for some d, then S is not 2-large.
We also ask whether these sets, or some similarly constructed modifications, are 2-large.
Question 3.6. Are the sets S of the kind constructed here 2-large?
Another potential question we can ask is about the polynomial version of Katznelson’s question. What if we consider the Bergelson-Leibman polynomial van der Waerden Theorem [1] with restricted differences? We pose one such question.
Question 3.7. For what sets S does a finite coloring of N contain a monochromatic {x, x + d, x + d2} with d ∈ S?
Progress on any of these questions would be interesting and would contribute to our general understanding of recurrence.
