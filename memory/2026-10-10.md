- `rm` is refused by the permission layer in agent runs here; `trash` works. About 66 MB of removed palace files sit in the macOS Trash.

- Codex's CLI default in `~/.codex/config.toml` is `gpt-6.1-sol`, not the model he named as his main one. Left as is; the docs describe what he said.
