## Recurring notes

- `updatedAt` drift trap: `personal-site/scripts/generate-skills-data.mjs` derives per-skill `updatedAt` from `git log -1 --format=%cI -- SKILL.md`. My first attempt bundled the JSON regen along with the submodule bump — sync-check CI failed because CI's git history resolves 35 skill files to **different** commit times than my sandbox does (CI: April/May commits; mine: July fallbacks). Fix was to commit **only** the submodule pointer and let CI regenerate its own JSON — which then produced a zero-diff and passed. Rule: don't commit the generated JSON unless a skill's content actually changed.
