### Session scope lessons (carry-over)

- WebFetch on `github.com/<repo>/commits/<branch>.atom` reliably returns the top-15 commit SHAs even for out-of-scope repos.
- `raw.githubusercontent.com` is on the public-network allowlist (returns 200 for any SHA/path), useful for hydrating individual files when `git fetch` is blocked.
- `codeload.github.com` and `api.github.com` for out-of-scope repos both return 403.
- Compare views (`/compare/A...B`) frequently 502/timeout for large ranges — the atom feed + `/commits/main/<path>` combo is more reliable.
- `git log -1 --format=%cI SKILL.md` is timing-sensitive to clone depth. Always `git fetch --unshallow` before running the personal-site generator, or the catalog will drift.
