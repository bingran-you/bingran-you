# Memory Palace — outer room

This is the 3D room for [Bingran You's Memory Palace](https://bingran.ai/palace).
The monitor opens the sibling `palace-inner` portfolio OS.

The app is built by the parent site's `npm run palace:build` command. Its
webpack output is served from `/palace/`; do not deploy this directory as an
independent website.

This directory is adapted from Henry Heffernan's
[`portfolio-website`](https://github.com/henryjeff/portfolio-website). See
[`NOTICE.md`](NOTICE.md) and [`LICENSE.md`](LICENSE.md) for attribution and
license details.
